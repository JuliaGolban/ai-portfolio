# 🎬 AI Visionary Portfolio

Емоційний кінематографічний сайт-візитка для AI-креатора. Побудований на
Next.js, Styled Components та Framer Motion.

## ✨ Особливості

- **Emotional Cinematic Style**: Глибока кольорова гама з ефектом Film Grain.
- **Custom Interactive Cursor**: Плавний курсор, що реагує на взаємодію.
- **Scroll Reveals**: Анімована поява контенту при прокручуванні.
- **Fully Responsive**: Ідеальна верстка для iPhone та десктопів.

## 🛠 Технології

- **Framework**: Next.js 14+ (App Router)
- **Styling**: Styled Components
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Validation**: Prop-types

## 🚀 Як запустити локально

1. Клонуйте репозиторій.
2. Встановіть залежності:
   ```bash
   npm install
   ```
